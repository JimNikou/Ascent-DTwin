about

Ascent-DTwin is an IHU open-source tool for viewing, creating, editing and deleting digital twins with live telemetry. Minimal DTaaS core: twin library (JSON), MQTT ingest, InfluxDB storage, Grafana viz, Jupyter analysis.

Library

Ascent-DTwin · International Hellenic University · MIT License · Built on INTO-CPS DTaaS concepts (third-party: Grafana, InfluxDB, Mosquitto MQTT, JupyterLab). See DTaaS upstream.
MQTT topic pattern: ascent/<twin-id>/telemetry · HTTP: POST /api/twins/<id>/telemetry
